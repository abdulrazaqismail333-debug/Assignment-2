# Assignment-2

📘 SDLC Review Questions

1️⃣ What is SDLC?

The Software Development Life Cycle (SDLC) is a framework used to develop software in a systematic and organized manner. It guides a project from planning to maintenance.

⸻

2️⃣ Why is SDLC Important?

SDLC is important because it:
	•	Improves software quality
	•	Reduces development risks
	•	Ensures requirements are met
	•	Helps manage time and costs effectively

⸻

3️⃣ Seven Phases of SDLC
	1.	Planning
	2.	Requirements Analysis
	3.	System Design
	4.	Development (Coding)
	5.	Testing
	6.	Deployment
	7.	Maintenance

⸻

4️⃣ Functional vs Non-Functional Requirements

   Functional Requirements         Non-Functional Requirements
   ⸻                           ⸻
   Define what the system does     Define how the system performs
   Login system                    Fast response time
   User registration               Security
   Search feature                  Reliability

⸻  

5️⃣ What Happens During Testing?

   The software is tested to identify and fix bugs, verify functionality, and ensure it meets user requirements.

⸻

6️⃣ Deployment vs Maintenance

  Deployment

  The process of releasing software for users to access and use.

  Maintenance

  The process of fixing bugs, improving performance, and updating features after deployment.

⸻

7️⃣ Waterfall vs Agile
  Waterfall               Agile
  ⸻                    ⸻  
  Linear process          Iterative process
  Highly flexible         Highly flexible
  Changes are easy        Changes are easy
  Continuous testing      Continuous testing

⸻  

8️⃣ Major Stakeholders in SDLC
	•	Clients/Customers
	•	Project Managers
	•	Business Analysts
	•	Software Developers
	•	Quality Assurance (QA) Testers
	•	End Users

⸻

9️⃣ What is User Acceptance Testing (UAT)?

   UAT is the final testing stage where end users verify that the software works as expected before it is officially released.

⸻

🔟 Why is Maintenance Important?

Maintenance ensures that software remains:
	•	Secure
	•	Reliable
	•	Up-to-date
	•	Free from critical bugs

⸻

✅ Conclusion

SDLC provides a structured approach to software development, helping teams build high-quality software efficiently from planning through maintenance.
